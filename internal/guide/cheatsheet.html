chat-term cheat sheet

A message that starts with . is a command. Anything else is typed into your terminal, then Enter.

Start here

  1. .projects - list your project folders
  2. .open 2 claude - open folder 2 and start claude (or codex, gemini, any command)
  3. Type your request as a normal message.
  4. A menu? Send its number, or use .up .down .enter
  5. .screen - show the whole screen. .c - stop (Ctrl-C)
  6. .ss - your sessions. .s 2 - switch to one

Directories

.pwdshow the current folder
.ls [path|n] [-a]list files, numbered
.tree [path|n] [depth]folder tree (default depth 2)
.cd <path|n>change folder
.cat <file|n> [from-to]show a file
.projectslist project folders, numbered
.open <n|folder> [cmd]new session in a folder

Sessions

.sslist tmux sessions, numbered
.s <n|name>switch to a session
.new [name] [dir] [cmd]start a new shell session
.backswitch to the previous session
.detachstop viewing; session keeps running
.kill [n|name]end a session (asks first)
.yesconfirm a pending kill
.rename <new-name>rename the active session

Keys

.enterpress Enter
.escpress Escape (interrupts Claude/Codex)
.tabpress Tab
.stabpress Shift+Tab (Claude: cycle modes)
.uparrow up
.downarrow down
.leftarrow left
.rightarrow right
.bsbackspace
.spacepress Space
.cCtrl-C (stop a program)
.dCtrl-D (end input / exit a shell)
.zCtrl-Z (suspend)
.lCtrl-L (clear screen)
.key <keys...>any tmux key names
.raw <text>type text without pressing Enter

View

.screenshow the whole current screen
.more [lines]screen plus scrollback (default 60)

Other

.help [all|command]how to get started (add all for every command)
.guidecheat sheet picture to keep on your phone
.statusbridge uptime, memory, active session

Numbers refer to the last list shown: .ls then .cat 3.

Key commands take a repeat count: .down 3. To type text that starts with ., begin it with ...

.help <command> explains one command with examples.
